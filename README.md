# MR. VICKY — Website

Apni YouTube channel ke liye link-landing website. GitHub Pages pe free host hogi.

## ⚡ Quick Setup

### Step 1: GitHub Pages on karo
1. Repo me **Settings** tab pe jao
2. Left menu me **Pages** pe click karo
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` aur `/ (root)` select karo
5. **Save** pe click karo

### Step 2: Wait 1-2 minutes
Link milega: `https://vikramnegi99.github.io/mr-vicky/`

### Step 3: Link use karo
Ye link apni YouTube video ke description me daal do — permanent rahega!

## ✏️ Links Kaise Change Karein

`index.html` ko GitHub ke web editor me kholo. Har link card aise dikhta hai:

```html
<a href="#" target="_blank" class="link-card fade-in">
    <div class="link-icon">💸</div>
    <div class="link-body">
        <div class="link-title">Online Earning Tools</div>
        <div class="link-desc">Best platforms & apps to earn money online</div>
    </div>
    <div class="link-arrow">→</div>
</a>
```

- `href="#"` ki jagah apna link daalo
- Title aur description me apna text likho
- Emoji change kar sakte ho
